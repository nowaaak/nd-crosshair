# Contributing

Thanks for your interest in ND Crosshair.

## Issues and feature requests

Bug reports and feature ideas are very welcome. Please use the [issue templates](https://github.com/nowaaak/nd-crosshair/issues/new/choose). English or German are both fine.

## Pull requests

This project does not accept pull requests. Development is done by the maintainer only. If you have an idea or found a fix, please open an issue and describe it there.

You are free to fork the project under the terms of the [MIT License](LICENSE).
